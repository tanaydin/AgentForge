# Development

Guides for humans and AI agents contributing to this repository.

- `coding-standards.md` — naming, structure, boundary rules
- `testing.md` — test layout and expectations

## Principles
- Prefer simple solutions over unnecessary abstraction.
- Respect layer boundaries (see `docs/architecture/`).
- Introduce a dependency only with an ADR that justifies it.
- Keep the domain pure.
- Update documentation when the architecture changes.
