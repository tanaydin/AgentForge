# Project management

A technology-neutral workflow. No PM tool is connected. Future integration *could* target
GitHub Projects, GitLab, Jira, Linear, or others.

## Work item hierarchy

```
Epic
 -> Feature
   -> Story
     -> Task
       -> Sub-task
```

## Work item types
- Bug
- Technical debt
- Security issue
- Research
- Spike

See `issues.md`, `branches.md`, `releases.md`.
