# Issues

- Every change starts as an issue (or work item) describing the problem and desired
  outcome.
- Issue templates live in `.github/ISSUE_TEMPLATE/` and (for GitLab) `.gitlab/`.
- Labels categorize type (bug, tech-debt, security, research, spike) and area.

## Flow

```
Issue -> Branch -> Commit -> Pull/Merge Request -> Review -> CI -> Merge
```
