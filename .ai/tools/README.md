# .ai/tools

## Purpose
Descriptors for external tools/MCP servers an agent may call: input/output schema, auth model, permissions. Descriptors only, no implementations.

## What belongs here
- Markdown or JSON descriptors
- Text, schemas, conventions

## What does NOT belong here
- Executable code
- Secrets
- Generated artifacts

## Example future files
- `.ai/tools/example.md`

## Dependencies that may eventually be introduced
